# Axle Keys

**Configurable CAD for things that actually get built.**

[axlekeys.com](https://axlekeys.com)&nbsp; · &nbsp;[Docs](https://axlekeys.com/docs)&nbsp; · &nbsp;[Connect your agent](https://axlekeys.com/connect)&nbsp; · &nbsp;[Roadmap](https://axlekeys.com/roadmap)

</div>

---

Axle Keys is a browser-based platform for creating configurable, buildable CAD models of
physical objects. You describe what you want to make — in Studio, or through your own AI
agent — and Axle turns it into a real parametric model you can measure, adjust, verify, and
take to fabrication.

**AI decides parameters and structure. Deterministic code builds the geometry.** A model is
generated by code from named parameters, not produced as a mesh — so it can be
re-configured without being re-generated, and what comes out the other end is dimensioned,
checkable, and manufacturable.

## One model, many outputs

- **3D exports** — STEP, STL, DAE
- **Shop drawings** — dimensioned projected views, as SVG, PDF, or DXF
- **Cut lists and nesting** — parts tabulated and laid out on real sheet stock
- **Materials** — a product stock palette assigned across parts, with real surfaces
- **Motion** — assembly animations, rendered to MP4
- **Embeddable configurators** — a live 3D configurator that runs on any website, in the
  visitor's browser, with no login and no inference at runtime

## Built to be operated by agents

Every action available in Studio is also available to an AI agent, through the same
controlled tools and against the same models. Builds run server-side, so an agent can work
with no browser tab open.

```
https://api.axlekeys.com/mcp
```

```bash
claude mcp add --transport http axle-keys https://api.axlekeys.com/mcp
```

Works with MCP clients including Claude and ChatGPT over OAuth — no local install, no API
keys. Writes are versioned, validated, and reversible, and every one records the reasoning
behind it.

→ [**AxleKeys/cad-engine**](https://github.com/AxleKeys/cad-engine) — the geometry engine, run
it on your own machine: build a model offline and get the same verdict axlekeys.com gives, in
about 55ms. Ships the free, open skills that teach your agent the whole workflow. MIT.

## Access

Axle Keys is in an **invitation-only beta**. Account creation needs a Keyholder code;
request one at [axlekeys.com](https://axlekeys.com). Docs, the roadmap, and every public
page are open to everyone, no account required.
